# AI Skills Directory

This directory contains AI skills that can be used for various tasks and workflows.

## Structure

Each skill is organized in its own subdirectory with the following structure:

```
skills/
├── skill-name-1/
│   ├── README.md          # Skill description and usage
│   ├── skill.json         # Skill configuration (optional)
│   └── ...                # Skill-specific files
└── skill-name-2/
    ├── README.md
    └── ...
```

## Adding a New Skill

To add a new skill:

1. Create a new subdirectory under `skills/` with a descriptive name
2. Add a `README.md` file describing your skill, including:
   - Purpose and functionality
   - Usage instructions
   - Requirements and dependencies
   - Examples
3. Include any additional files needed for your skill

## Guidelines

- Use clear, descriptive names for your skill directories
- Include comprehensive documentation in each skill's README
- Follow consistent naming conventions (lowercase with hyphens)
- Keep each skill self-contained within its directory
