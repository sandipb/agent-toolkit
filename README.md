# Skills Directory

A repository for publishing and sharing AI skills.

## Overview

This repository serves as a centralized location for AI skills that can be used across various projects and workflows. Each skill is contained in its own subdirectory under the `skills/` folder.

## Structure

```
skills-directory/
├── skills/               # Main directory for all AI skills
│   ├── README.md        # Documentation for the skills directory
│   └── [skill-name]/    # Individual skill directories
└── README.md            # This file
```

## Getting Started

Browse the [skills directory](./skills/) to explore available AI skills. Each skill has its own README with detailed documentation on usage and requirements.

## Contributing

To add a new AI skill:

1. Create a new subdirectory in the `skills/` folder
2. Include a comprehensive README.md documenting your skill
3. Add all necessary files for your skill to function
4. Follow the guidelines in [skills/README.md](./skills/README.md)
